# page-lock screenshot kit

Copy the `vault` folder's contents into a folder called `Plugin Showcase` in any Obsidian vault. Enable this plugin first. The demo contains no personal information and does not change plugin settings. For Gallery and Fullscreen Image, copy both kits to the same folder to share the photos. Remove `Plugin Showcase` when finished.

Open `Capture checklist` for the coordinated shot list. Save real captures in this repository's `screenshots` directory using the filenames listed there. Existing published screenshots remain until their replacements are ready. Do not publish a placeholder as a real screenshot.

See `vault/Photo credits.md` for the theme sources and photo licenses where included.
